Configuração inicial

Feito uma vez só. O token fica guardado no repositório, criptografado com a sua senha.

Criar token fine-grained no GitHub
  1. Em "Repository access", escolha "Only select repositories" e marque só este repositório.
  2. Em "Repository permissions", ponha "Contents" em "Read and write".
  3. Não marque mais nada.
Mínimo de 8 caracteres. Recomendado: uma frase de 5 palavras ou mais. Não há como recuperar a senha.

Importar ideias

Escolha um arquivo JSON no formato {"ideas": [...]} ou uma lista de ideias. Uma ideia com o mesmo título (ou o mesmo id) de uma que já existe é atualizada: os campos que vierem no arquivo substituem os atuais, e os que faltarem ficam como estão. O arquivo é lido só no navegador e gravado criptografado.
